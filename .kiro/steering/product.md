# Product Overview

**SchoolSync** is a comprehensive school administration mobile application built with Flutter. It provides a unified platform for managing school operations across three user roles:

## User Roles

- **Admin**: Organization management, classroom oversight, teacher/student approval, attendance tracking, and comprehensive assessments
- **Teacher**: Class management, student monitoring, attendance marking, and assessment creation
- **Student**: View attendance, access classroom materials, check results, receive notifications, and communicate with teachers

## Core Features

- **Multi-role authentication** with role-based access control
- **Real-time chat** using Socket.IO for communication between users
- **Push notifications** via Firebase Cloud Messaging
- **Attendance management** with date-based tracking and visualization
- **Assessment system** for comprehensive student evaluation
- **Organization management** with license key validation
- **Auto-update system** with in-app download and installation
- **Join request workflow** for teachers and students with approval/rejection flow

## Technical Characteristics

- Cross-platform mobile app (Android/iOS support)
- Backend API integration with REST endpoints
- Real-time bidirectional communication
- Offline-capable with SharedPreferences for local state
- Material Design UI with custom theming
